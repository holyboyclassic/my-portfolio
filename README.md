# Anuoluwa Portfolio

A modern portfolio website for a junior frontend developer, built with React and Vite. It highlights recent projects, technical skills, and contact information in a clean, responsive single-page layout.

## Overview

This portfolio includes:

- A hero section with branding and introduction
- Project cards with live demos and GitHub links
- A skills section summarizing core frontend stack
- Responsive navigation for desktop and mobile
- Contact links for email, GitHub, and LinkedIn
- A polished dark theme with accessible, mobile-friendly styling

## Tech Stack

- React
- JavaScript
- Vite
- CSS
